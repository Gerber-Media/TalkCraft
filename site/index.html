Was TalkCraft kannWhat TalkCraft does

Jede Stimme eine Spur

A track per voice

Vorlage mit Sprachkette pro Sprecher, Mikrofon-Erkennung und Soundcheck fürs Audio-Interface.

A template with a voice chain per speaker, microphone detection and a soundcheck for your interface.

Ferngäste ohne Installation

Remote guests, nothing to install

Gäste kommen per Link im Browser dazu und nehmen verlustfrei bei sich auf; die Datei landet synchron auf ihrer Spur.

Guests join from a browser link and record lossless on their side; the file lands in sync on their track.

Sprache aufbereiten

Clean up speech

Rauschen, Übersprechen, Atmer und Schmatzer reduzieren, Sprecher angleichen, Pausen kürzen, Füllwörter schneiden.

Reduce noise, crosstalk, breaths and mouth clicks, match speakers, shorten pauses, cut filler words.

Transkription auf dem eigenen Rechner (Whisper), Schnitt am Text, SRT/WebVTT, Shownotes mit Kapiteln.

Transcription on your own computer (Whisper), editing by text, SRT/WebVTT, show notes with chapters.

Erster Start: die WarnungenFirst launch: the warnings

Warum warnen macOS und Windows? Beide Systeme vertrauen Programmen aus dem Internet erst, wenn sie mit einem kostenpflichtigen Zertifikat des Herstellers signiert sind (Apple: Developer ID mit Notarisierung, Windows: Code-Signing-Zertifikat). TalkCraft ist ein kostenloses Projekt und hat dieses Zertifikat noch nicht. Die Warnung heißt also „unbekannter Hersteller“, nicht „Schadsoftware gefunden“. Ob die Datei unverändert ist, kannst du oben unter Download prüfen selbst nachsehen.

Am einfachsten: Installiere TalkCraft per Befehl. Dann kommt gar keine Warnung, denn die Warnungen hängen an einer Markierung, die nur der Browser heruntergeladenen Dateien gibt. Der Befehl lädt die neueste Version von GitHub, prüft die Prüfsumme und installiert sie. Was er genau tut, kannst du vorher lesen: install.sh, install.ps1.

macOS und Linux, im Terminal:

curl -fsSL https://talkcraft.gerber.media/install.sh | sh

Windows, in PowerShell (Windows fragt danach nur noch nach Administratorrechten):

irm https://talkcraft.gerber.media/install.ps1 | iex

Lieber den normalen Download? Dann musst du die Warnungen einmal bestätigen, danach startet TalkCraft ohne Rückfrage:

Why do macOS and Windows warn? Both trust software from the internet only when the maker has signed it with a paid certificate (Apple: Developer ID plus notarization, Windows: a code signing certificate). TalkCraft is a free project and doesn't have one yet. So the warning means "unknown developer", not "malware found". You can check that the file is unchanged under Check a download.

Easiest: install TalkCraft with one command and there's no warning at all, because the warnings hang on a mark that only the browser puts on downloaded files. The command fetches the newest version from GitHub, checks its checksum and installs it. Read what it does first if you like: install.sh, install.ps1.

macOS and Linux, in Terminal:

curl -fsSL https://talkcraft.gerber.media/install.sh | sh

Windows, in PowerShell (Windows then only asks for administrator rights):

irm https://talkcraft.gerber.media/install.ps1 | iex

Prefer the normal download? Then confirm the warnings once; after that TalkCraft starts without asking:

macOS

macOS meldet sich zweimal: beim Öffnen der DMG-Datei und beim ersten Start der App. Beide Male gehst du so vor:

  1. Doppelklicke die Datei. Es erscheint „… wurde nicht geöffnet. Apple konnte nicht überprüfen, ob … frei von Schadsoftware ist“. Klicke Fertig (nicht „In den Papierkorb legen“).
  2. Öffne Systemeinstellungen › Datenschutz & Sicherheit und scrolle ganz nach unten zu „Sicherheit“.
  3. Dort steht „… wurde blockiert, um deinen Mac zu schützen“. Klicke Dennoch öffnen, bestätige mit Passwort oder Touch ID und im nächsten Fenster noch einmal mit Dennoch öffnen.

Danach ziehst du TalkCraft in den Ordner „Programme“ und startest es von dort; beim ersten Start wiederholst du die drei Schritte. Der Knopf erscheint nur etwa eine Stunde nach dem Öffnungsversuch.

Der alte Weg „Rechtsklick › Öffnen“ funktioniert seit macOS 15 nicht mehr.

Schon heruntergeladen? Entferne im Terminal die Download-Markierung, bevor du die DMG öffnest. Dann warnt weder die DMG noch die App:

xattr -d com.apple.quarantine ~/Downloads/{{FILE_DMG}}

Ist TalkCraft schon installiert:

xattr -dr com.apple.quarantine /Applications/TalkCraft.app

macOS asks twice: when you open the DMG file and when you first start the app. Both times:

  1. Double-click the file. You see "… Not Opened. Apple could not verify … is free of malware". Click Done (not "Move to Trash").
  2. Open System Settings › Privacy & Security and scroll down to "Security".
  3. It says "… was blocked to protect your Mac". Click Open Anyway, confirm with your password or Touch ID, and click Open Anyway once more.

Then drag TalkCraft into Applications and start it from there; on the first start repeat the three steps. The button only shows for about an hour after the attempt.

The old "right-click › Open" trick no longer works since macOS 15.

Already downloaded? Remove the download flag in Terminal before opening the DMG, and neither the DMG nor the app will warn:

xattr -d com.apple.quarantine ~/Downloads/{{FILE_DMG}}

If TalkCraft is already installed:

xattr -dr com.apple.quarantine /Applications/TalkCraft.app
Windows
  1. Im Browser: Edge meldet eventuell „… wird nicht häufig heruntergeladen“. Fahre über den Download, klicke … › Beibehalten › Mehr anzeigen › Trotzdem beibehalten.
  2. Beim Öffnen des Installers: „Der Computer wurde durch Windows geschützt“. Klicke auf Weitere Informationen, dann auf Trotzdem ausführen.
  3. Benutzerkontensteuerung: „Herausgeber: Unbekannt“ – mit Ja bestätigen.

Die installierte App startest du über das Startmenü, dort kommt keine Warnung mehr.

ZIP ohne Installation: Bevor du entpackst, Rechtsklick auf die ZIP-Datei › Eigenschaften › unten Zulassen anhaken › OK. Sonst warnt Windows bei jedem Start.

Ist auf Windows 11 die „Intelligente App-Steuerung“ eingeschaltet, blockiert sie unsignierte Programme ohne Ausnahme. Dann geht es erst mit einer signierten Version von TalkCraft.

  1. In the browser: Edge may say "… isn't commonly downloaded". Hover the download, click … › Keep › Show more › Keep anyway.
  2. Opening the installer: "Windows protected your PC". Click More info, then Run anyway.
  3. User Account Control: "Publisher: Unknown" – click Yes.

Start the installed app from the Start menu; it won't warn again.

Portable ZIP: before extracting, right-click the ZIP › Properties › tick Unblock › OK. Otherwise Windows warns on every start.

If Smart App Control is on (Windows 11), it blocks unsigned programs with no exception. Then you'll need a signed TalkCraft release.

Linux

Linux warnt nicht, aber die AppImage muss ausführbar sein: Rechtsklick › Eigenschaften › „Als Programm ausführen“, oder im Terminal:

Linux doesn't warn, but the AppImage has to be executable: right-click › Properties › "Allow executing as program", or in a terminal:
